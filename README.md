# Resetpoints Main Site Copy With Cases

Отдельная GitHub-копия текущего deploy-сайта Resetpoints с добавленным разделом кейсов.

## Что изменено

- На главную страницу добавлен компактный блок `Кейсы` после логотипов клиентов.
- Добавлена развернутая страница кейса: `/ru/cases/bank-offsite-summer-2026/`.
- Фото кейса вынесены в `case-assets/`.
- Для GitHub Pages поправлены относительные пути к основным ассетам.
- Русская страница получила корректные `lang`, `title` и `description`.

## Техническая заметка

Исходный сайт находится в виде готового SPA-бандла. Раздел кейсов добавлен отдельным enhancement-слоем:

- `case-insert.css`
- `case-insert.js`
- `case-page.css`

Так можно показать и протестировать UX без ручной правки минифицированного React-кода.
